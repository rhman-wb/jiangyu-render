## 0. 这次失败的根本原因（必须先读懂）

1. **你没有看过自己渲染的图。** 日志 D-014 写着"无视觉环境"，于是你用 `imgstat.py` 生成 ASCII 亮度网格来"自检"。这个前提是错的：**Claude Code 的 Read 工具可以直接打开 PNG/JPG 并看到图像内容。** 枕头放反、材质全变木纹、B 方案物件漂进 A 方案，这些都是一眼可见的问题，全部因为没看图而漏掉。
   → 从现在起，**每一张渲染图都必须用 Read 工具打开并逐张写出视觉检查结论**（第 5 章），这是硬性要求，不能用统计数字代替。
2. **QA 只检查几何。** 229 项全过，却不检查材质、方案隔离、朝向、颜色。→ 第 6 章新增检查项。
3. **材质按"白模阶段的 clay 材质"路由**，导致所有白模时用 `clay_wood` 的子件（地毯、抱枕、盖毯、孩子家具、陶罐、挂画、坐垫…）都被刷成了胡桃木。→ 第 4.1 节重构。

## 2. 规格变更（同步写入 CLAUDE.md）

### 2.1 木色（替换 CLAUDE.md 6.2、材质表中 walnut / walnut_dark）
- 业主认为当前胡桃木不好看：贴图（smoked_walnut_veneer）纹理花、偏橙红。
- **默认木色 = A 方案**：以 `refs/livingroom_cabinet.jpg` 的实木柜为准——中深棕、略偏冷、**直纹**（纹理平直、少山纹）、低饱和、哑光（粗糙度 0.5–0.55）。平均色目标约 `#5E4330`（sRGB），饱和度明显低于现状。
  - 优先换一张 Poly Haven 上纹理更平直的深色木皮/胡桃类贴图；如果只能沿用原贴图，必须通过 Hue/Saturation 节点降饱和（约 ×0.65）、色相往黄偏移一点，压掉红橙，并把纹理尺度放大，减少"花"感。
- R1 中还要做 **B 浅胡桃/茶色**（平均约 `#7A5C43`）和 **C 橡木原木色**（平均约 `#B48E66`，直纹）两套木色，用于对比图（第 7 章）。业主看图选定后，全屋统一换成选定的那一套。
- 木色材质用参数（例如 `WOOD_PRESET = 'A'|'B'|'C'`）切换，**不要复制几何**。

### 2.2 门（修改 CLAUDE.md 4.3"门"）
- 全屋木门不变（木色随 2.1）。
- **公卫门、主卫门改为玻璃平开门**：胡桃木（选定木色）细框，框宽约 4cm；玻璃 = **长虹玻璃（竖向细条纹）+ 磨砂夹胶**（看起来是长虹纹理、半透光、看不到人影）；黑色细长竖拉手 30cm。默认关闭。
  - 材质建议：Transmission 0.6–0.8，粗糙度 0.35–0.5（磨砂），法线或凹凸用竖向条纹（周期约 1.5–2cm）。
- **阳台东端通往露台的门（W15 上的 glass_door）是开发商玻璃门**：深灰铝框（`window_frame_graphite`）+ 清玻璃（`glass_clear`），**绝不能是木门**。主卧通往露台的落地门窗同样是深灰铝框加清玻璃。

### 2.3 孩子房（替换 CLAUDE.md 5.10 的配色；仍是"成品家具示意"，**任何家具不得用木色**）
- **儿子房**：家具（床、衣柜、书桌、书架、椅子）主图用**鼠尾草绿** `#9CAF94`（柔和灰绿，哑光）；床品奶白 + 浅灰绿；地毯浅燕麦色加绿色几何纹。另出一张 **雾霾蓝** `#8FA7B8` 版对比图（第 7 章）。不用鲜艳的绿或蓝。
- **女儿房**：家具用**燕麦米色** `#D9C7AD`（比地砖深一档，让家具轮廓从地面和墙面中"跳出来"）；点缀色**雾粉** `#D8B4AE`，用在床品、窗帘、地毯、抱枕、一两个小物件上；床品和窗帘为奶白加雾粉。
- 孩子房的木色部件（桌腿、床脚等）也改成家具本色，**一律不用胡桃木**。

### 2.4 全屋色彩规则（新增 CLAUDE.md 6.5，并写入 QA）
| 层级 | 面积占比 | 允许的颜色 | 用途 |
|---|---|---|---|
| 基底 | ≈75% | 奶白 `wall_paint` / `cabinet_white`、暖米 `floor_tile_800` | 墙、顶、地、定制柜门板 |
| 木色 | ≈15% | **只有一种**：选定木色（walnut / walnut_dark） | 室内门、卫生间门框、西墙实木柜、岛台侧板、餐桌、电视柜、床头柜、书桌、开放格内衬、飘窗台面 |
| 软装 | ≈8% | 燕麦 `fabric_oat`、焦糖 `leather_caramel` | 沙发、窗帘、床头软包、地毯、床品、坐垫 |
| 点缀 | ≤2% | 客厅只用墨绿 `fabric_olive` 和砖红 `ceramic_brick`；孩子房各用 2.3 的颜色 | 单椅、抱枕、陶盆、小物件 |

- **以下物件禁止使用木色材质**：地毯、抱枕、靠枕、盖毯、床品、坐垫、窗帘、陶罐/陶盆、挂画画芯、孩子房全部家具、A 方案脚踏（焦糖皮）、绿植。
- **黑色只能用作细线条**：拉手、灯杆、电视边框、淋浴隔断框、窗框（深灰）。**禁止大块黑色**：A 方案中古单椅改为墨绿（坐垫和靠背墨绿面料，胡桃木框），移动电视的支架改为细杆式（第 3 章 #14），植物不许是黑色方块。

### 2.5 画面基调（替换 CLAUDE.md 第 8 章"曝光目标"）
- **白天、明亮、以自然光为主**，像"晴天上午的样板间实拍"，不是傍晚开灯的氛围图。
- **白平衡以日光为准**：白墙在图中必须读作白色或极浅的暖白，不能是黄色、土色或棕色。室内 3000K 灯只做局部暖色点缀（灯带、台灯、吊灯周围），不能主导整张图的色温。
- **曝光以白墙为准**：受光白墙区域的 sRGB 平均值约 200–225，R−B 差 ≤ 18（量化目标见 QA）；卫生间和北向孩子房也必须看清每一件物品，不允许死黑。
- 实现建议（按需组合，记录到 decisions_log）：
  - 色彩管理用 AgX，Look 改成 `Base Contrast` 或 `Medium Contrast`（不用 Medium High）；
  - 每个机位单独调曝光，一般在 +0.7～+1.5；
  - 太阳色温 5600–6000K；世界光可以适当提高；
  - 卫生间、孩子房这类无直射光的房间，可以在窗外加不可见的面光补光（`visible_camera=False`），或在室内加隐藏的柔光补光，**模拟真实摄影补光**；
  - 必要时在 Compositor 里做白平衡和曲线校正。

### 2.6 楼层与窗外环境（替换 CLAUDE.md 第 8 章"窗外环境"）
- 当前 HDRI `roof_garden` 是**地面层、玻璃顶棚下的花园**，露台图看起来像建在花园步道旁边，和"3 楼"不符。必须更换。
- 要求：
  - 室外地坪放在 **Z = −6.0m**（3 楼），铺草地和园路；
  - 在南北两侧、距外墙 5–15m 处放树冠高度约 6–10m 的树（Poly Haven 树模型，或带 alpha 的树木贴片），树冠顶部大致和窗户齐平或略高；
  - 远处放 1–2 栋浅色住宅楼体块；
  - HDRI 选 Poly Haven 上**晴天或薄云、无明显建筑、天空干净**的户外 HDRI，只用它提供天空和环境光。
  - 从室内窗口看出去，应该是"略高于树冠、俯视花园"的视角。

### 2.7 鸟瞰图（修改 01/02）
- 背景改为**纯浅色**（约 `#F2F0EC`）。实现方式：Film Transparent，渲染后合成到浅色底；或者用 Light Path 的 Is Camera Ray 让世界背景对相机显示为浅色。
- `hide_ceilings` 时，必须**同时隐藏所有安装在顶面上的东西**：吸顶灯、筒灯、灯槽灯带、吊灯（含吊杆）、空调出风口、窗帘盒。画面里不允许出现悬空的灯具或发光条。

## 4. 实现要点
