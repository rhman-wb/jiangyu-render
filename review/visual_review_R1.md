# R1 逐张视觉检查（visual_review_R1.md）

按 REWORK 第 5 章协议：每张图用 Read 工具打开 + 视觉模型逐项核对。
检查链路：Read（打开 PNG）→ 视觉分析（按"必须看到"逐项提问）→ 结论。
本环境 Read 图片返回 CDN 上传，视觉核对经 analyze_image 模型完成（每张图的提问内容即"必须看到"清单）。

**通用"不得出现"清单（每张图都查）**：木纹刷到软装（地毯/靠垫/床头软包/陶罐）、悬浮物、
方案串场（A 图出现 B 物件或反之）、大面积黑/深灰墙柜、整片发黄发棕、死黑角落、物体穿插、
近景物体遮挡超过 15% 画面、任何文字/logo/水印/人物。
