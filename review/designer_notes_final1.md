# FINAL1 设计师施工说明（designer_notes_final1.md）

> 供业主转交设计师：以下事项为效果图之外、**施工阶段必须落实**的内容（每条一句话）。
> 尺寸口径与 `review/layout_proposals_final1.md`（R1–R7 批复版）一致。

1. **孩子房安全（无论床位）**：两间孩子房北窗（W01/W06）加装开窗限位器 + 隐形防护网。
2. **公卫无障碍**：马桶侧 L 形扶手、淋浴区壁挂折叠凳与竖向扶手的固定点须**墙内预埋加固**；淋浴隔断干区侧加挡水条（30mm 宽 × 25mm 高）+ 挡水条内侧线性地漏；淋浴区地面防滑砖（与干区可区分）。
3. **父母房电气预留**：床下感应夜灯、父母房门 → 公卫过道地脚灯（离地 0.30m、间距约 1.35m ×3）、床头两侧阅读壁灯（离地 1.40m）的**预留线路与开关**。
4. **玄关收纳**：户内通高鞋柜 0.70m（西墙 y−6.20…−5.50 段，0.35m 深，中段 0.35m 高开放格、底部 0.15m 架空放常穿鞋 + 感应灯）+ 电梯口通高鞋柜 1.10m（x2.30…3.40）；户内 + 电梯口合计 1.80m（工单目标 2.00m 经复核不可达：东延穿 W28 墙、南延撞端景柜，见 D-064）。
5. **厨房西墙**：浅吊柜取消，改 0.35m 深通高储物柜（z 0–2.30，上下两段门）；下柜门板底边离地 0.10m、内凹踢脚 6cm。
6. **A 方案电视墙**：背景板 3.0m × 通高（凸出 3cm），四周 15mm 暗槽内藏 3000K 灯带；北端竖格栅 0.60m 宽（20mm 板 + 20mm 缝，深灰色金属型材）；格栅与背景板之间白墙挂画 1.0×0.7（中心离地 1.50m）。
7. **灯具色温建议**：主照明 4000K、点缀（灯带/壁灯/台灯/夜灯/地脚灯）3000K——**仅为效果图设定值**，实际选购由业主与设计师按现场效果确定；同一空间内色温建议统一分档。
8. **电视柜**：悬空电视柜收窄为 2.4m 居中（云白柜体 + 4cm 胡桃台面线 + 底部灯带），电视位与沙发对位不变。
9. **主卫**：淋浴固定玻璃隔断边框改深灰细框（≤20mm）；防水百叶帘按"放下 1/3"安装（帘头盒置于窗洞顶）。
